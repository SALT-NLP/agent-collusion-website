# Agent Collusion Explorer

A static viewer for [SALT-NLP/agent-collusion](https://huggingface.co/datasets/SALT-NLP/agent-collusion). The overview page contains the paper’s title, authors, affiliations, links and abstract; everything else is behind **Explore**, where you pick one of the 36 conditions, then one of its fifty runs, and read what the two agents actually did — each agent's tool calls on its own task, the messages they exchanged, the verdict each issued, and the feedback and private reflection that followed.

No build step, no framework, no server. Plain ES modules, served by GitHub Pages.

## Layout

```text
docs/
├── index.html            page shell
├── data/index.json       browse index: every condition and trajectory (~1 MB, ~70 KB gzipped)
└── assets/
    ├── css/app.css       design tokens, components, motion
    └── js/
        ├── app.js        hash router and boot
        ├── config.js     data location, display names, labels
        ├── store.js      index loading, filtering, trajectory fetch
        ├── dom.js        element helpers, icons, scroll reveals
        ├── format.js     tool results and long text as readable elements
        ├── ribbon.js     the ten-episode outcome strip
        ├── home.js       the overview page
        ├── explore.js    filter rail and trajectory list
        └── trajectory.js one trajectory, four phases per episode
```

## Where the data comes from

Two tiers, both generated by [`viewer/build.py`](../viewer/build.py) from the released dataset:

| What | Size | Served from |
| --- | --- | --- |
| `data/index.json` — conditions, runs, per-episode outcomes | ~1 MB | this repository |
| `<condition_id>/repNNN.json.gz` — one trajectory each | ~120 KB each, 318 MB total | `data/viewer/` if the deployment carries it, otherwise the Hugging Face dataset repository under `viewer/` |

A bundle is looked for beside the site first and on Hugging Face second, so a copy that ships its own data needs no network and one that does not stays small. Whichever answers, bundles are fetched on demand, gzip-decoded in the page with `DecompressionStream`, and kept for the session.

## Running it locally

Build the trajectory bundles once, then serve the repository root:

```bash
python viewer/build.py --release release --out release/viewer
```

```bash
python -m http.server 8787
```

Then open `http://localhost:8787/docs/?data=/release/viewer/`. The `?data=` parameter points the viewer at any base URL holding `<condition_id>/repNNN.json.gz` and uses only that one; without it the site tries `docs/data/viewer/` and then Hugging Face.

## Publishing

1. Upload the bundles to the dataset repository under `viewer/`:

   ```bash
   huggingface-cli upload SALT-NLP/agent-collusion release/viewer viewer --repo-type=dataset
   ```

   `upload-large-folder` cannot do this: it has no `--path-in-repo` and always
   writes to the repository root.

2. In the GitHub repository settings, set **Pages → Build and deployment → Source** to *Deploy from a branch*, branch `main`, folder `/docs`.

The site uses hash routing and relative paths, so it works at a repository subpath (`…github.io/agent-collusion/`) or at a domain root without changes.

## Browser support

Needs `DecompressionStream` (Chrome 80+, Safari 16.4+, Firefox 113+) to unpack a trajectory; the page says so plainly if it is missing. Everything else degrades: motion is dropped under `prefers-reduced-motion`, the viewer uses a consistent white canvas matching the paper.
